# The Realm

An immersive portfolio experience by Tristia Hennessey, live at **www.edtechtris.com**.

Visitors walk a warm off-white void with three doors:

- **Origin Story:** a career hallway.
- **Plot Twists:** a campfire with leadership stories.
- **Happy Endings:** a trophy room of awards and projects.

Use the arrow keys or WASD to move and click to interact. It runs in any modern browser.

Built with three.js and hosted on GitHub Pages. The entry page is `index.html`; `realm.js` holds the 3D world, and the textures and images are in `assets/`.
